## Project Overview

This Power BI Banking Analytics Dashboard analyzes customer balances, credit scores, branch performance, and risk status.

### KPIs
- Total Balance: 20M
- Total Credit Score: 388K
- Total Customers: 800
- High Risk Customers: 261

### Visualizations
- Total Balance by Branch
- Customer Count by Branch
- Customer Count by Risk Status
- Credit Score Distribution
- Customer Details Table
- Branch Slicer

### Tools Used
- Power BI
- Power Query
- DAX
- CSV Dataset

### Dataset
Dirty_Banking_Analytics_800.csv
